# The ref each fleet-build leg builds, and the GOOS set it builds it for.
#
#   <repo>[:<module-dir>] <ref> [goos[,goos]...]
#
# The ref points a leg at the branch carrying that consumer's migration while it
# is still in flight, so the gate measures the tree that is about to merge
# rather than a main that still pins the old daemonkit. scripts/fleet-build.sh
# --ref REPO prints it and the workflow checks that out, so both halves of the
# gate read this file through one parser. Every consumer carries a line and the
# script refuses a file that leaves one out, because an omitted leg silently
# builds a branch nobody chose. The GOOS set stays optional and defaults to
# darwin.
#
# A ref names a branch or tag, never a commit. Any repo listed here may also be
# another leg's cone peer, and a cone peer is fetched with git clone --branch,
# which no commit satisfies. The script refuses a commit-shaped ref outright.
#
# A consumer whose Go module does not sit at its checkout root spells the
# subdirectory on the repo column after a colon. The colon rather than a fourth
# column because the GOOS column is optional, so a bare trailing field could not
# be told apart from it; and on the repo column rather than a column of its own
# because "<repo>:<module-dir>" is exactly the module path minus the
# github.com/<owner>/ prefix — the script derives both the checkout path and the
# identity a leg's go.mod must declare from that one string instead of guessing
# either. Everything that addresses a leg by name — --ref, --cone, the
# workflow's matrix.repo, a cone peer — still takes the bare repo, because that
# is what the repository is called and what actions/checkout clones it to. The
# subdirectory is relative to the checkout and spelled as plain path segments:
# the script refuses an absolute one, one that escapes upward, and `.`, which
# would name the repository root that dropping the colon already names.
#
# GOOS defaults to darwin: daemonkit is macOS-only and its consumers ship there.
# binrun also ships linux and is the fleet's linux canary for the portable
# subset, so its leg builds both and a linux-only break stops being invisible.
# Every entry in the set names a platform: the script refuses an empty one,
# which would leave a leg building nothing and reporting the pass it starts at.
